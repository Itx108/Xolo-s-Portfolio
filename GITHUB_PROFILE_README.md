## Featured engineering project

### CutFlow

A full-stack salon and barber operations platform covering appointments, staff scheduling, customers, services, branches, POS, inventory, memberships, vouchers, commissions and SaaS subscription workflows.

The project includes:

- PostgreSQL-level protection against overlapping staff appointments;
- live availability refresh and rescheduling logic;
- South African timezone-aware booking rules;
- customer-data de-identification after completed services;
- an installable PWA/offline shell that avoids caching sensitive customer data;
- database migrations for production upgrades;
- deployment through Vercel.

**Live:** https://cutflow.co.za  
**Repository:** https://github.com/Itx108/Cutflow
